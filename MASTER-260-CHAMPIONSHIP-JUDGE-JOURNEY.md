# MASTER-260 — Championship Judge Journey

## Objective
Harden the first-minute judge experience without changing the verified decision engine.

## Intended journey
1. **SITE** — understand the proposed site and development input.
2. **SPATIAL** — inspect land-use, zoning, cadastral and terrain context.
3. **ENVIRONMENT** — surface flood, ecology, geoscience and monitoring pathways.
4. **POLICY** — connect applicable planning rules and evidence state.
5. **ASSESS** — run the planning assessment.
6. **WHAT-IF** — compare alternative development scenarios.
7. **DECISION → LCP** — consolidate evidence, recommendations, review gaps and planner verification boundary.

## Guardrail
This checkpoint documents the championship journey only. It does not convert source-context layers or agency pathways into statutory verification, and it does not alter the current production deployment.

## Current release anchor
MASTER-259 is the code checkpoint preceding this audit. Its CI run must remain the release gate for this documentation-only checkpoint.
