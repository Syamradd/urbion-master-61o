# URBION HORIZON — MASTER-70 Release

## Release intent
MASTER-70 is the championship-ready consolidation checkpoint for the URBION spatial decision-support prototype.

## Verified architecture
- FastAPI decision API
- Spatial/TOD context engine
- Typology-aware RT MBMB 2035 rule retrieval
- Applicability + compliance evaluation
- Site suitability screening
- Explainable recommendation + decision confidence
- Evidence-state routing and decision trace
- Deterministic judge demo scenarios
- Responsive spatial dashboard with Leaflet map

## Evidence integrity
URBION does **not** present planned, unavailable, discovery-only or unverified external sources as live statutory evidence. External GIS/portal connectivity remains explicitly disclosed until query evidence is proven.

## Judge flow
1. Open the dashboard.
2. Run TOD-COMPLY.
3. Run SHOP-FAIL.
4. Run OFFICE-REVIEW.
5. Show the recommendation, confidence, evidence intelligence and decision trace.
6. Close with: “URBION is decision support, not statutory approval.”

## Safety boundary
The suitability score and confidence score are screening/traceability indicators. They are not approval probability, legal certification, or a substitute for planner/authority verification.

## Release rule
Do not add fake GIS evidence merely to improve the demo. A visible evidence gap is preferable to a fabricated result.
