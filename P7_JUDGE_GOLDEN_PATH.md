# URBION HORIZON — Judge Golden Path

## Championship sequence
1. **ASSESS** — establish site, PBT, typology and proposal inputs.
2. **MAP** — reveal spatial evidence and layer provenance.
3. **EVIDENCE** — show LIVE / SOURCE CONTEXT / NO FEATURE / QUERY ERROR / EVIDENCE GAP states.
4. **WHAT-IF** — compare independent proposal variants.
5. **DECIDE** — show recommendation, confidence and WHY trace.
6. **PLANNER REVIEW** — expose missing evidence and next action.
7. **KM/OSC** — surface submission readiness and blockers.

## Presentation contract
- The map remains the visual focal point.
- A judge must understand the current state without opening developer tools.
- Every live/public source has visible provenance.
- Loading and failure states are intentional UI states, not blank panels.
- Evidence gaps are actionable, not hidden.
- Visual polish must not imply statutory approval.

## Failure-safe states
`LOADING` · `LIVE` · `SOURCE CONTEXT` · `NO FEATURE` · `QUERY ERROR` · `SOURCE UNAVAILABLE` · `EVIDENCE GAP` · `REVIEW REQUIRED` · `NOT READY`

## Freeze gate
A judge-facing change is ready only after permanent CI, browser QA, diff review and controlled production verification. No direct edits to Phase 1 geometry are permitted.
