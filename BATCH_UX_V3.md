# Championship UX V3

## Purpose
- Make the first screen read as a planning workflow rather than a collection of tools.
- Keep the map/evidence surface primary and remove intrusive floating workstation panels.
- Make source-layer opacity controls act on the actual Leaflet evidence layer.
- Expand State and PBT selection using PLANMalaysia PBT naming as the reference vocabulary.
- Add dependent land-use category, activity and proposal/development selections.

## Design basis
The hierarchy follows common professional dashboard guidance: strongest information first, predictable grid/reading flow, restrained accent color, clear typography hierarchy, and uncluttered presentation. PLANMalaysia i-Plan itself exposes state/PBT search, current/zoning land-use layers and multiple basemap choices; URBION V3 adapts that planning workflow into a compact screening dashboard without claiming statutory verification.

## Evidence boundary
PBT and land-use option labels are interface vocabulary. They do not imply that every PBT has the same policy coverage in the deterministic engine. The existing evidence boundary remains unchanged: live GIS rendering is source context, not statutory approval.
