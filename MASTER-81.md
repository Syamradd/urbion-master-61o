# MASTER-81 — Planning Value Hardening

Phase C hardening checkpoint.

## Purpose
Make the planning-value layer testable and explicit before moving to scenario/what-if intelligence.

## Acceptance criteria
- Planning value is decision-support, not statutory approval.
- COMPLY produces strengths, decision drivers and next actions.
- NON-COMPLIANCE prioritises redesign before proceeding.
- Non-MBMB/local-rule gaps remain evidence-gated.
- Regression tests protect all three pathways.
