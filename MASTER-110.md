# MASTER-110 — GIS Layer Workspace

Focused judge-facing GIS workspace for parcel, land-use, zoning, TOD catchments and decision visualization.

- Shows lot number and area in m² / ha.
- Provides layer toggles for Parcel, Land Use, Zoning, TOD and Decision.
- Uses Leaflet + OpenStreetMap for spatial grounding.
- Demonstration geometry is explicitly disclosed and is never treated as statutory evidence.
- Verified cadastral / planning evidence remains the required path for decision-safe GIS claims.
