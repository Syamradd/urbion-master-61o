# MASTER-177 — Championship Readiness

## Product loop
Site → Spatial → Policy → Evidence → Compliance → What-If → Decision → Planner Review → KM/OSC.

## Release principles
- Deterministic decision logic remains authoritative.
- Source context and calculated outputs remain explicitly qualified.
- Spatial placeholders are rejected.
- What-If shows baseline/scenario delta.
- Planner Review shows blockers and next evidence/action.
- CI runs targeted lanes in parallel and a full regression gate.
- No output is presented as statutory approval.

## Championship gate
Actual GitHub Actions success is required before calling the release green.
