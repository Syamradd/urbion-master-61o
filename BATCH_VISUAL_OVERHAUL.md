# Championship Visual Overhaul

## Goals
- Reduce dashboard cognitive overload by removing floating workstation and Decision OS popups.
- Establish one visual hierarchy with compact live status.
- Lock dark/light URBION HORIZON logo variants as scalable SVG assets.
- Make spatial evidence visible on the map rather than only in text panels.
- Add 400 m, 800 m, 1 km and 1.5 km calculated screening/context rings.
- Use explicit site and TOD reference symbols plus a visible relationship line.
- Add grouped source-context overlay controls for declared zoning/land-use, environmental and mobility layers.
- Preserve evidence boundaries: rendered layers are source context, not statutory confirmation.
