# MASTER-193 — Championship Release Lock

## Locked product loop
**Site Assessment → Map Studio → Evidence → What-If → Decision Center → Planner Review → LCP Intelligence → KM/OSC**

## Hard gates
- Real spatial input required; placeholders rejected.
- Evidence states remain distinguishable.
- Live/portal source failures become review gaps, never fabricated values.
- Remote values are escaped before UI rendering.
- What-If exposes baseline/scenario delta.
- Recommendations remain planner-review outputs.
- KM/OSC remains workflow readiness support, never approval.
- Full GitHub Actions regression must be GREEN on the release commit.

## Release principle
No feature is considered championship-ready merely because code exists. The current main commit and its CI result are the release evidence.
