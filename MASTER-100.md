# MASTER-100 — Championship Release Gate

## Release contract
- Core assessment remains the source of statutory-rule outcomes.
- Planning value explains findings and next actions.
- What-If compares intervention pathways.
- Evidence contract distinguishes decision-safe evidence from disclosed gaps.
- GIS payload provides map-ready decision features.
- Decision Center composes the full story in one response.
- Judge Mode provides deterministic showcase output.

## Championship output
URBION is positioned as an explainable spatial decision-intelligence prototype: it does not replace statutory planning approval, but makes the reasoning, evidence burden and intervention pathway visible.
